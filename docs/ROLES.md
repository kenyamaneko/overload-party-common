## 優先度サマリ

| 優先度 | 役職 | 理由 |
|--------|------|------|
| 今すぐ | 法務（契約ひな形） | 外注開始の前提条件 |
| 近いうち | ゲームバランサー | カード実装が進む前に数値設計の土台が必要 |
| 近いうち | カードアーティスト | 契約ひな形ができ次第、発注開始できる状態にしておく |
| 近いうち | ADアシスタント | イラスト外注の進行管理に必須。発注開始と同時に稼働 |
| β前 | シナリオライター | ストーリーエンジンの箱は完成済み。中身はβまでに |
| β前 | プレイテスター | ある程度遊べる状態になってから |
| リリース前 | ペネトレーションテスト（スポット） | 最低1回は外部検証 |
| リリース後 | QA / 運営 / マーケ / リリースマネージャー | 運用フェーズ |
