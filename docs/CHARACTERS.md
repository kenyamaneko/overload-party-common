## SHE — Smile Horizon Express

**テーマ: 配達員と動物たち — 笑顔と荷物を世界中どこまでも届ける**

「**Smile Horizon Express**」は世界最大の EC サイト。SHE のメンバーはその**配達員**で、それぞれ固有の**相棒動物**と共に、世界のあらゆる場所へ笑顔と荷物を届ける。仲間が増えるほど配達網が広がり、チーム全体の効率が上がる——それが SHE の「エコシステムシナジー」。制服はオレンジのベストと配達キャップ、大きな配達バッグがトレードマーク。

| キャラ | 元サービス | イラスト構図 | プロフィール |
|--------|-----------|------------|------------|
| **えくぼ** | EC2 | 少女（人間）。オレンジのショートヘア、配達ベスト、大きな配達バッグ、橙の笛。元気いっぱいの笑顔で荷物を抱えて走る | 看板配達員。明るく面倒見がよく、どんな荷物も笑顔で届ける。仲間のまとめ役 |
| **アリゲーテナ** | ECS/Fargate | 動物（ワニ）。コンテナ型の箱を積み重ねて運ぶ小さなワニ。Scale Up でどんどん大きくなる | 「どこへでも運ぶぜ」が口癖。自分のサイズより大きい荷物も強引にこなす豪快な配達員 |
| **クジラの統率者〈クジランティス〉** | EKS | 人間＋動物。配達リストを片手にした少女を中心に、周囲を巨大な鯨の群れが囲み、空や海を泳いでいる構図 | 寡黙な統率者。鯨の群れと共に配達員全員を俯瞰し、最適なルートを瞬時に割り振る |
| **ラフメイカー** | SageMaker | 少女（人間）。白衣の上から配達ベスト、大きな丸眼鏡。実験中に爆発したフラスコを唇に当てがら「初めてではありません」と日記を書いている | 「笑顔を作る方程式を研究中」と言いながら配達する変わり者。実は陣営で一番の分析屋 |
| **むらた** | Lambda | 少年（人間）。クリーム色の巻き毛、白シャツ、羊飼い杖+鈴。ぼんやりとした表情で立っている | 普段は待機中。「え、呼んだ？」と呼ばれた瞬間だけ飛び出してくる |
| **アデリース** | RDS | 動物（アデリーペンギン）。首からIDカードをさげ、配達バッグを背負った几帳面なペンギン。手帳を開いてルートを確認している | 予約した配達ルートを絶対に変えない几帳面屋。「Reserved Instance です、変更は受け付けません」 |
| **オオロバ** | Aurora | 動物（大きなロバ）。背中に大量の配達バッグを積んだ屈強なロバ。仲間の荷物が増えるほどどんどん荷車が大きくなる | 仲間が増えるほど強くなる。バックエンドが充実するほど荷台が拡張され、Insight が増加する |
| **えりり** | S3 | 少女（人間）。年齢不詳。藤色の三つ編み（=S3の3）、白ローブ、オレンジのブローチ。広大な倉庫の前に非常に大きなバケツを両手で持って立つ | 倉庫番。預かった荷物は何があっても失くさない。Smile 配達社の最古参 |
| **ダイノ** | DynamoDB | 動物（謎の小型恐竜）。赤いリボンタイをつけて、荷物の前でいつもそわそわ待機している | 需要に応じて一気にペースを上げる気分屋。On-Demand で本気を出した日の配達量は伝説 |
| **メリーモ** | ElastiCache | 動物（ふわふわの白い羊）。白とオレンジのボーダーのマフラーをつけ、素早い身のこなしで荷物を運ぶ | Memcached（陽気でたくさん稼ぐ）か Redis（寡黙で精度を上げる）——今日どちらのモードかはその日次第 |
| **だっくん** | DAX | 動物（黄色い小さなあひる）。ダイノのそばにぴったり寄り添っている | ダイノの配達を高速化する忠実な相棒。「ガァ！」 |

## 天気使い

**テーマ: 天候師 — 天候を操り、空の力で仲間を守る者たち**

天気使いのメンバーはそれぞれ異なる**天候**を司る術師「天候師」。雲の障壁、海上の嵐、稲妻の一撃、雪の凍結、夜空の静寂——天候そのものが防御であり武器。衣装は透明感のある青と白を基調に、空や海のモチーフが散りばめられる。

| キャラ | 元サービス | イラスト構図 | プロフィール |
|--------|-----------|------------|------------|
| **ソラ** | Azure VM | 少女。空色ロングヘア、白ロングコート、丸筆+パレット型小盾。天候：雲（雲の障壁で守る） | 穏やかだが芯が強い。「この雲がある限り、誰も倒れさせない」 |
| **アサギリ** | App Service | 少女。薄紫の半透明ベール、白と薄緑のグラデーション衣装。朝靄をまとって佇む静かな姿。天候：霧（ダメージを半減する乳白色の霧） | おっとりとした保護者気質。インシデントが来る前にそっと霧で包んで被害を和らげる |
| **コウテン** | ACI | ボサボサ髪の少年。学ラン（あるいは特攻服風のセーラー服）の裾が強風で常にバサバサと音を立てている。荒れた海原を背景に、嵐を纏いながら仁王立ち。天候：嵐（荒海を支配する暴風雨） | 喧嘩っ早いが仲間思いの熱血ヤンキー。「四の五の言ってねえで、俺が道を開けてやらぁ！」と真っ直ぐ突進するパワーファイター |
| **空即蒼色** | AKS | 少女。白銀の長髪と白コートがふわりと広がり、どこまでも続く青空の中に浮かんでいる。周囲には「お前を消す方法」で有名なイルカ（カイル君）のような生物が何匹も楽しげに飛んでいる。天候：晴れ | 冷静沈着な指揮官。嵐のコウテンを「よい風だ」と評する器量。カイル君たちは「何かお困りですか？」と常に聞いてくる |

| **ライ** | Azure Functions | 青髪の小柄な少年。オーバーサイズのパーカーのフードを被り、ヘッドホン着用。衣服のどこかに稲妻マーク（Azure Functionsのロゴ）が入っている。常にスマホや携帯ゲーム機をいじってだらけている。天候：雷（一瞬の閃光で敵を貫く） | 極度のめんどくさがり屋のダウナー男子。普段は「だりー」と動かないが、呼ばれた（トリガーされた）瞬間だけ、目にも止まらぬ雷撃を落とし、何事もなかったかのようにゲームに戻る |

## しゅがーらぼ

**テーマ: お菓子の国 — ポップでキュートなスイーツワールド**

しゅがーらぼのメンバーはカラフルな**お菓子の世界**の住人。見た目は甘くてかわいいが、秘める火力は全陣営最高クラス。4色（赤・青・黄・緑）がデザインの随所に散りばめられる。ただし可用性は低め——お菓子は壊れやすい。

| **クラン**（Container） | Cloud Run | 少女。ツインテール（4色リボン）、エプロンドレス。白い箱型バッグ（コンテナ）に詰まったお菓子。**クラン（Functions）と同一人物** | 食べるモード。もぐもぐ食べて力を得る食いしん坊 |

## 調律部

**テーマ: 吹奏楽部 — 放課後の音楽室から、世界を鳴らせ**

調律部のメンバーは**「吹奏楽部ミラクル」**の部員たち。校舎の一角にある音楽室を拠点に、楽譜（= DB）を大切に管理しながら日々の練習に励む。衣装は深紅のブレザー制服に白いシャツ。コンクールを目指す熱量と、放課後の気ままなセッションが共存する青春チーム。
