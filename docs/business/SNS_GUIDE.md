# Overload Party — SNS運用ガイド

SNSが苦手な人向けに、「何を・いつ・どう書くか」を具体的に示す。

---

## アカウント設計

| 項目 | 内容 |
|------|------|
| プラットフォーム | Twitter/X（メイン）。余裕があれば Instagram（イラスト特化） |
| アカウント名 | @overload_party（例） |
| 表示名 | Overload Party｜IT擬人化カードゲーム |
| プロフィール | 「ITインフラを擬人化した対戦型カードゲーム。ガチャなし。2026年秋リリース予定。開発: @[個人アカウント]」 |
| 固定ツイート | ティザーサイトへのリンク＋キービジュアル |

## 投稿カレンダー（週間）

無理のないペースで継続することが最重要。週3回で十分。

| 曜日 | 投稿タイプ | 例 |
|------|-----------|-----|
| 月 | **開発進捗** | 「今週実装した機能」「UIデザインの変更前→変更後」等 |
| 水 | **キャラクター・世界観** | キャラ紹介、カード能力の解説、陣営の設定 |
| 金 | **エンジニアネタ / 雑談** | エンジニアあるある、開発裏話、困ったこと |

## 投稿テンプレート

### 開発進捗系

```
【開発進捗】

対戦画面のUIを大幅にリニューアルしました。
カードの能力テキストが見やすくなったのと、
フィールドのゾーン配置を直感的に変更。

Before → After で見るとこんな感じです。

#OverloadParty #gamedev #indiedev
```

### キャラクター公開系

```
【キャラクター紹介】えくぼ ― SHE陣営

笑顔で世界中にデータを届ける配達員。
状況に応じてサイズを変え、どんな荷物も運びこなす。

🎨 イラスト: @[イラストレーター名]

#OverloadParty
```

### エンジニアネタ系

```
カードゲームのバランス調整をしてたら、
「本番環境でしか再現しないバグ」みたいな
微妙なコンボが見つかった。

これはこれでゲームの味になるのか、
それとも修正すべきか…。

#OverloadParty #gamedev
```

## 投稿のコツ

| やること | やらないこと |
|---------|-------------|
| 画像・動画を必ずつける（テキストだけの投稿はリーチが低い） | 宣伝臭の強い投稿（「今すぐ事前登録！」の連呼） |
| ハッシュタグは2〜3個（#OverloadParty #gamedev #indiedev） | ハッシュタグの大量付与（スパムに見える） |
| 他の開発者やエンジニアの投稿にリアクション・リプライ | フォロワー数を気にしすぎる |
| 失敗談や悩みも素直に書く（共感を得やすい） | 完璧な発信だけを目指す（続かなくなる） |
| 毎週同じ曜日・時間帯に投稿する（習慣化） | 不定期に大量投稿→長期間沈黙のサイクル |

## 投稿時間帯

エンジニアがSNSを見る時間:

| 時間帯 | 理由 |
|--------|------|
| **8:00〜9:00** | 通勤時間 |
| **12:00〜13:00** | 昼休み（最もエンゲージメントが高い） |
| **21:00〜23:00** | 帰宅後のリラックスタイム |

**推奨: 昼12時台に予約投稿。** Twitter/X の予約投稿機能を使えば、投稿を事前にまとめて設定できる。

## フォロワーの増やし方

広告を使わずにフォロワーを増やす方法:

| 施策 | 効果 | 手間 |
|------|------|------|
| **技術記事からの流入** | 高 | 中（記事の末尾にアカウントリンク） |
| **陣営診断のシェア** | 高 | 低（一度作れば自動で拡散） |
| **キャラ公開ツイートの定期投稿** | 高 | 低（イラスト完成ごとに1投稿） |
| **エンジニア系のハッシュタグで交流** | 中 | 中（#gamedev, #indiedev, #個人開発 等） |
| **他のインディー開発者との相互フォロー・交流** | 中 | 低 |
| **開発者個人アカウントからのリツイート** | 中 | 低 |

**最初の100フォロワーが一番難しい。** 技術記事の公開と同時にアカウントを紹介するのが最も効率的。1記事がバズれば数百フォロワーを一気に獲得できる。
