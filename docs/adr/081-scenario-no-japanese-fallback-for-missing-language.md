# ADR-081: 要求言語のスクリプトが無いときに日本語へフォールバックしない

## ステータス

Accepted (2026-08-11)

## 結論

シナリオスクリプト配信において、要求言語のスクリプトが存在しない場合に日本語へ自動的に差し替える処理を行わず、見つからないエラーをそのまま返す。配信基盤側の一時的な障害 (権限エラー・通信エラーなど) は見つからないエラーと区別し、別のエラーとして返す。

## 背景・課題

以前は要求言語のスクリプトが無い場合に日本語へ自動フォールバックしていた。この仕様には次の問題があった。

- クライアントは実際にどの言語で表示されているかをサーバーから受け取れないため、要求言語と実際の配信言語が一致しているかをクライアント側で別途管理する必要があった
- 翻訳の未整備が自動的に隠蔽され、長期間気づかれずに残る余地があった
- 要求言語で取得できなかったときにどう振る舞うか (別言語で再取得する・エラー表示するなど) をクライアント側で選べず、サーバーが一方的にフォールバックしていた
- フォールバックするかどうかの判定を「配信基盤がオブジェクトを見つけられない」エラーだけに絞り込む必要があり、権限エラーやネットワークエラーなど対象外のケースと混同しないよう実装上常に注意を払う必要があった

## 不採用案

### 日本語への自動フォールバックを維持する

却下。上記の問題が解消されないまま残る。
