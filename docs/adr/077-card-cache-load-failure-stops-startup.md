# ADR-077: カード定義のインメモリキャッシュはロード失敗時に起動を止める

## ステータス

Accepted (2026-08-11)

## 結論

カード定義をサービス起動時に読み込むインメモリキャッシュは、ロードに失敗した場合サービスを起動させず異常終了する。カード定義の一部が欠けた状態のまま部分的に起動を継続する設計は採らない。

## 背景・課題

カード定義はデッキ構築・対戦判定などプレイヤー体験に直結する判定のたびに参照される。ロードに失敗した状態のまま起動を続けると、プレイヤーが所持しているカードの定義がキャッシュに存在しないというデータ整合性の破れが、そのままユーザー向けレスポンスに混入する。さらに、カード定義が欠けた状態でのデッキ有効性判定は、未所持カードでの対戦開始を許してしまう、または正当なデッキを弾いてしまうなど、どちらの向きに誤っても体験上の実害につながる。

起動失敗はサービスの readiness を失敗させ、新しいインスタンスがトラフィックを受けずに旧インスタンスが引き続きリクエストを処理する。中途半端な状態で新インスタンスをトラフィックに晒すより安全である。

## 不採用案

### ロードに失敗したカード定義があっても部分的に起動を続ける

却下。データ整合性が壊れた状態を隠したまま稼働することになり、対戦判定の誤り (false positive / false negative) がプレイヤー体験に直接影響する。readiness による安全弁も放棄することになる。
