# ADR-069: プレイヤー設定更新は PUT で部分更新セマンティクスを採用する

## ステータス

Accepted (2026-08-11)

## 結論

プレイヤー設定の更新エンドポイントは HTTP メソッドとして PUT を使うが、セマンティクスは全項目上書きではなく部分更新とする。送信しなかったフィールドは現状維持し、ゼロ値で上書きしない。

## 背景・課題

クライアントが特定のフィールド (例: 言語設定) だけを変更するつもりで部分的なリクエストボディを送ると、リクエストに含めなかった他のフィールドがゼロ値扱いになって上書きされてしまう事故が起きうる。REST の慣用に厳密に従うなら部分更新は PATCH を使うべきだが、エンドポイントを PATCH に切り替えるとクライアント側の呼び出し方法の変更が必要になる。

## 不採用案

### PATCH に変更し、REST の慣用に厳密に従う

却下。呼び出し元 (クライアント) への影響が生じる。部分更新という実質的なセマンティクスさえ守れれば、HTTP メソッド名の慣用より呼び出し元への影響回避を優先する。

### 全項目必須の PUT のまま運用する (クライアントに全項目送信を強制する)

却下。クライアント側の実装ミスや通信の都合で一部フィールドが欠落した場合に、意図しないゼロ値上書きが起きる設計のままになる。
