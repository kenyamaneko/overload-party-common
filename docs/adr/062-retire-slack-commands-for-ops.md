# ADR-062: 運用操作の Slack コマンド経由の実行を廃止する

## ステータス

Accepted (2026-05-06)

この ADR は [ADR-009](009-slack-commands-gke-via-github-actions.md) を置き換える。

## 結論

環境の起動停止などの運用操作を Slack コマンドから実行する仕組みを廃止する。Slack コマンドを受け取る実装 (受け口) とその手前のプロキシを撤去し、GitHub Actions の手動実行に一本化する。

これにより、受け口の実装・依存関係・認証情報を保守し続ける必要がなくなる。

## 背景・課題

[ADR-009](009-slack-commands-gke-via-github-actions.md) は、運用操作を Slack コマンドから実行し、その実行自体は GitHub Actions に委ねる方式を採用した。この設計では、Slack コマンドを受け取り GitHub Actions の実行をトリガーする独立した受け口を、実行方式そのものとは別に維持し続ける必要があった。

運用を続けたところ、この受け口を使う頻度は低く、実装・依存する外部サービス・認証情報のローテーションといった保守コストに見合わなかった。GitHub Actions は元々 UI から手動でトリガーする手段を備えており、受け口を経由しなくても同じ操作を実行できる。

この決定は運用操作の起動経路に関するものであり、GKE や gateway のホスティング方式の見直しとは独立している。

## 不採用案

### 受け口を維持し続ける

Slack から直接操作できる利便性は残るが、実行頻度に対して保守コストが見合わないと判断し、不採用とした。
