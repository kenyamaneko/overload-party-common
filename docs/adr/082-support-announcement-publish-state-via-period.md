# ADR-082: Support のお知らせは公開状態を専用の状態列でなく期間の開始・終了だけで表現する

## ステータス

Accepted (2026-08-11)

## 結論

Support のお知らせは、公開状態 (下書き・予約公開・公開中・期限切れ) を管理する専用の状態列を持たず、公開期間の開始日時と終了日時だけで表現する。状態の切り替えは期間を表す値の更新だけで完結させ、公開・非公開を切り替える専用の操作は設けない。

## 背景・課題

Support のお知らせは運用者が作成から公開までを一人で完結させる運用で、複数人による承認を経て世に出す工程を持たない。一方、同じ「お知らせ的なコンテンツ」を配信する news は外部ソースから記事を機械的に取り込むため、取り込みと公開可否の判断を分離する必要があり、承認前後を区別する状態列と、誰がいつ承認・却下したかを記録する仕組みを持つ。

両サービスは公開までの工程の有無が根本的に異なるため、同じ状態表現を採用すると、承認工程を持たない Support 側では実際には遷移しない状態や使われない承認記録の仕組みを抱えることになる。

## 不採用案

### news と同様に専用の状態列と承認記録の仕組みを持つ

却下。Support のお知らせには承認者による判断という業務上の実体が無く、実際には使われない状態と承認記録を持つだけになる。
