# ADR-080: scenario のスクリプト配信元をリクエスト単位で切り替えない

## ステータス

Accepted (2026-08-11)

## 結論

スクリプトの配信元 (GCS / ローカルファイルシステム) は起動時に一度だけ決定し、以後はリクエストごとに切り替えない。特定の呼び出しだけ配信元を変える経路 (例: GCS 読み取り失敗時にローカルへ自動的に切り替える) は設けない。

## 背景・課題

開発機で GCS 認証なしに動かしたい、CI の e2e テストでテスト用データを配信したいという運用上の要求から、スクリプト配信元を切り替え可能にする必要があった。一方で切り替えの単位をリクエストごとにすると、設定ミスや障害時にどちらの配信元を読んでいるかが呼び出しごとに変わり得る。特に本番環境で意図せずローカル/テスト用データを読み込んでしまう事故を防ぎたい。

## 不採用案

### GCS 読み取り失敗時にローカルへフォールバックする

却下。読み取りごとに配信元が変わり得る構成になり、本番の障害時にテスト用データが混入する経路を作ってしまう。フォールバックが発生したこと自体の検知も難しくなる。
