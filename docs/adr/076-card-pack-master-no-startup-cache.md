# ADR-076: パックマスターは起動時キャッシュせず配布のたびに参照する

## ステータス

Accepted (2026-08-11)

## 結論

配布パックのマスターデータは、カード定義と異なり、起動時にサービス内メモリへロードするキャッシュ戦略を採らない。配布リクエストのたびに都度データベースを参照する。

## 背景・課題

カード定義は読み取り専用のホットパス (デッキ構築・対戦判定) で参照され件数も多く、起動時に一括ロードしてメモリキャッシュする設計を採っている。パックマスターに同じ戦略を適用するかどうかを検討した。

パック配布は「その時点のパック定義に従って配布された」ことを後から再現できる必要があり、起動時にロードしたスナップショットを使い続ける設計では、いつどの定義で配布したかが曖昧になる。また、配布済みのプレイヤーに対して後からパック内容を遡って再配布する運用を許容しており、ローリング再起動中に新旧のインスタンスが異なる定義を持つ状態で配布すると、遡及配布の結果がインスタンスごとに変わってしまう。パックの件数はカード定義と比べて少なく、配布はデッキ構築・対戦判定ほど高頻度なホットパスでもないため、都度参照によるレイテンシ増は無視できる。

## 不採用案

### カード定義と同じ起動時キャッシュ戦略をパックマスターにも適用する

却下。配布履歴の監査可能性 (どの時点の定義で配布したかを再現できること) と、パック内容を後から遡及して再配布する運用の両方が、インスタンスごとに異なる定義を参照しうる起動時スナップショットと相容れない。
