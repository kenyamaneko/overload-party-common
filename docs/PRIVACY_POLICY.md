# Overload Party — プライバシーポリシー

**施行日:** 2026-XX-XX
**最終更新日:** 2026-XX-XX

---

Key and Notes（以下「当方」）は、Overload Party（以下「本アプリ」）の提供にあたり、ユーザーの個人情報を以下のとおり取り扱います。

---

## 1. 収集する情報

### 1.1 ユーザーが提供する情報

| 情報 | 目的 | 必須/任意 |
|------|------|----------|
| メールアドレス | アカウント認証（Firebase Authentication 経由） | 必須 |
| ユーザー名（表示名） | ゲーム内でのプレイヤー識別 | 必須 |

### 1.2 自動的に収集する情報

| 情報 | 目的 |
|------|------|
| Firebase UID | ユーザー識別・認証 |
| ゲームプレイデータ（対戦履歴、デッキ構成、勝敗結果） | ゲーム機能の提供・ゲームバランス調整 |
| 課金履歴（購入アイテム、購入日時） | 購入管理・カスタマーサポート |
| アプリのログ情報（リクエストID、エラーログ） | 障害対応・サービス改善 |
| 接続情報（IPアドレス、接続日時） | 不正利用防止・セキュリティ |

### 1.3 収集しない情報

- 位置情報
- 連絡先・電話帳
- カメラ・マイクデータ
- 端末内のファイル
- 第三者への広告目的のトラッキング情報

---

## 2. 利用目的

収集した情報は、以下の目的にのみ利用します。

1. **ゲームサービスの提供・運営** — アカウント管理、対戦マッチング、デッキ管理、課金処理
2. **サービスの改善** — ゲームバランスの調整、不具合の修正、パフォーマンス向上
3. **不正利用の防止** — チート対策、不正アクセスの検知
4. **カスタマーサポート** — お問い合わせへの対応、購入に関するトラブル解決
5. **法令に基づく対応** — 法令上の義務を履行するために必要な場合

広告配信やマーケティング目的での第三者への情報提供は行いません。

---

## 3. 情報の保管

| 項目 | 内容 |
|------|------|
| 保管場所 | Google Cloud Platform（リージョン: asia-northeast1、東京） |
| 認証情報 | Firebase Authentication（Google 提供） |
| ゲームデータ | Cloud SQL（PostgreSQL） |
| 暗号化 | 通信時: TLS 1.2以上、保管時: Google Cloud のデフォルト暗号化 |

---

## 4. 第三者提供

ユーザーの個人情報は、以下の場合を除き第三者に提供しません。

1. **ユーザーの同意がある場合**
2. **法令に基づく場合** — 裁判所の命令、法律上の義務がある場合
3. **サービス提供に必要な業務委託先** — 以下のサービスに限定

| 委託先 | 目的 | プライバシーポリシー |
|--------|------|---------------------|
| Google（Firebase Authentication） | ユーザー認証 | https://firebase.google.com/support/privacy |
| Google（Cloud Platform） | データ保管・サーバー運用 | https://cloud.google.com/privacy |
| Apple（App Store） | iOS課金処理 | https://www.apple.com/legal/privacy/ |
| Google（Google Play） | Android課金処理 | https://policies.google.com/privacy |

---

## 5. ユーザーの権利

ユーザーは、以下の権利を有します。

| 権利 | 内容 | 手続き方法 |
|------|------|-----------|
| **開示請求** | 保有する個人情報の開示 | 下記お問い合わせ先まで |
| **訂正・追加** | 個人情報の内容の訂正 | アプリ内設定またはお問い合わせ |
| **利用停止** | 個人情報の利用停止 | 下記お問い合わせ先まで |
| **削除（退会）** | アカウントおよび関連データの削除 | アプリ内のアカウント削除機能 |

アカウント削除を行った場合、以下のデータが完全に削除されます:
- ユーザー情報（ユーザー名、Firebase UID）
- デッキデータ
- 課金で取得したカード・コレクション（復元不可）
- 対戦履歴

> **注意:** アカウント削除は取り消せません。課金済みアイテムの返金は、各プラットフォーム（Apple / Google）の返金ポリシーに従います。

---

## 6. 未成年者のプライバシー

本アプリは全年齢を対象としていますが、16歳未満のユーザーが本アプリを利用する場合は、保護者の同意のもとでご利用ください。16歳未満のユーザーから意図的に個人情報を収集することはありません。16歳未満のユーザーの情報が収集されたことが判明した場合、速やかに削除します。

---

## 7. Cookie・トラッキング

本アプリは Cookie を使用しません。第三者の広告トラッキングツール（Google Analytics、広告SDK等）は導入していません。

---

## 8. プライバシーポリシーの変更

本ポリシーを変更する場合は、アプリ内通知または公式サイトにて事前に告知します。重要な変更がある場合は、施行日の少なくとも30日前に通知します。

---

## 9. 準拠法・管轄

本ポリシーは日本法に準拠し、日本法に従い解釈されるものとします。
