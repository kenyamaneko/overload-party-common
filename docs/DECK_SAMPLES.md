# Overload Party — 最適化デッキサンプル

**勝率最大化を目的とした構築例。** 不要な陣営カードは採用せず、汎用カードを最大限活用する。

**構築方針:** コアカードは **3積み**で引きの安定性を確保。1枚採用は制限カードとメタカードに限定。
