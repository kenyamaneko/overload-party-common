# イラスト外注 — 契約時の著作権チェックリスト

**目的:** イラストレーターへの発注時に、契約書に盛り込むべき著作権関連の条項をまとめたガイドです。

> **注意:** 本ガイドは参考資料です。実際の契約書作成時は、弁護士への相談を推奨します。

---

## 1. 契約形態の選択

| 形態 | 内容 | 推奨度 |
|------|------|--------|
| 著作権譲渡 | 著作権（財産権）を発注者に譲渡 | 最も安全だが報酬が高くなる。嫌がるイラストレーターも多い |
| **独占利用許諾** | 著作権はイラストレーターに残るが、独占使用権を付与 | **推奨** |
| 非独占利用許諾 | 著作権はイラストレーターに残り、他での使用も可 | 非推奨（同じイラストを他案件に使われうる） |

**推奨: 独占利用許諾（永続ライセンス）** — 著作権はイラストレーターに残したまま、「このイラストを使えるのは発注者だけ」とする形。個人開発では報酬面・交渉面で現実的なバランスが取れる。ただし、利用範囲と永続性を契約書に明記することが必須。

---

## 2. 契約書に盛り込むべき条項

### 2.1 独占利用許諾の範囲（必須）

契約書で以下の利用を明確に許諾してもらうこと:

```
甲は、成果物について以下の利用を独占的に行う権利を有する。
乙は、成果物を甲以外の第三者に利用許諾してはならない。
本許諾は期間の定めなく存続し、契約終了後も許諾済みの利用は継続できるものとする。
```

| 利用態様 | 具体例 |
|---------|--------|
| ゲーム内表示 | カードイラスト、プロフィールアイコン、ローディング画面 |
| アプリストア掲載 | App Store / Google Play のスクリーンショット、プロモーション画像 |
| 販促・広告 | 公式サイト、SNS、プレスリリース、PV |
| グッズ展開 | 将来的な物販（アクリルスタンド、カードスリーブ等） |
| 改変 | トリミング、色調補正、エフェクト追加、UIへの組み込み |

**「永続ライセンス」が特に重要。** この記載がないと、契約終了時にゲームからイラストを全部外す必要が出てくる。

> **著作権譲渡を選ぶ場合の注意:** 譲渡契約にする場合は、著作権法第27条（翻案権）・第28条（二次的著作物の利用権）を含むことを必ず明記すること。第61条2項により、明示しないとこれらの権利は譲渡されないと推定される。

### 2.2 改変の許諾（必須）

著作者人格権（同一性保持権）との関係で、改変について明確に合意しておくこと:

```
乙は、甲が成果物をゲームへの組み込み、販促、グッズ制作等の目的で
改変（トリミング、色調補正、エフェクト追加、レイアウト調整等）することに
同意する。
```

この合意がないと、以下の問題が発生しえます:

- イラストのトリミング・色調変更ができない（同一性保持権）
- クレジット表記を強制される（氏名表示権）
- ゲーム内での公開を差し止められる（公表権）

> **補足:** 著作者人格権は譲渡できない権利（一身専属権）。「不行使特約」として一括で書く方法もあるが、イラストレーターの心理的抵抗が大きい場合は、上記のように具体的な利用態様への同意という形にすると受け入れられやすい。

### 2.3 イラストレーター自身の利用（要協議）

独占許諾の場合、イラストレーターがポートフォリオ等に載せられるかを明確にしておくこと:

| 利用態様 | 推奨方針 |
|---------|---------|
| ポートフォリオ・実績紹介 | 許可（リリース後に限る） |
| SNSへの投稿 | 許可（リリース後に限る。「Overload Party イラスト担当」等の記載OK） |
| 同人誌・ファンアート | 要協議 |
| 他案件での流用・転売 | 禁止（独占許諾の核心） |

**推奨:** ポートフォリオ・SNS投稿は許可する。イラストレーターのモチベーション維持と宣伝効果の両面でメリットがある。

### 2.4 納品物の仕様（必須）

| 項目 | 指定内容 |
|------|---------|
| ファイル形式 | PSD（レイヤー分け）+ PNG（統合版） |
| 解像度 | 350dpi 以上 |
| カラーモード | RGB（デジタル用途） |
| レイヤー構成 | キャラクター / 背景 / エフェクトを分離 |
| 納品媒体 | クラウドストレージ経由 |

**レイヤー分けの重要性:** カードUI上でのレイアウト調整、将来的なアニメーション対応、差分イラスト制作のために、レイヤー分けされた元データの納品が必須です。

### 2.5 第三者の権利侵害がないことの保証（必須）

```
乙は、成果物が第三者の著作権、商標権、肖像権その他いかなる権利も
侵害しないことを保証する。万一、第三者から権利侵害の申立てがあった場合、
乙は自己の費用と責任においてこれを解決するものとする。
```

### 2.6 クレジット表記（任意・要協議）

| 方針 | 内容 |
|------|------|
| クレジット表記あり | ゲーム内クレジット画面にイラストレーター名を記載 |
| クレジット表記なし | 契約で氏名表示権の不行使を明記 |
| ペンネーム指定 | イラストレーターが指定するペンネームで記載 |

**推奨:** イラストレーターのモチベーション維持と信頼関係構築のため、クレジット表記ありが望ましいです。

### 2.7 修正・リテイクの条件（重要）

| 項目 | 推奨条件 |
|------|---------|
| ラフ段階の修正 | 回数無制限（方向性の擦り合わせ） |
| 線画・着色後の修正 | 2回まで無料、以降は追加費用 |
| 大幅な方向転換 | 別途見積もり |

### 2.8 支払条件

| タイミング | 割合 | 目的 |
|-----------|------|------|
| 契約時（着手金） | 30〜50% | イラストレーターの制作保証 |
| 納品・検収完了時 | 残額 | 品質確認後の支払い |

## 3. 契約時のチェックリスト

- [ ] 独占利用許諾の範囲が明記されているか（ゲーム内・販促・グッズ・改変）
- [ ] 永続ライセンス（契約終了後も利用継続可能）が明記されているか
- [ ] 改変への同意（トリミング・色調補正・エフェクト追加等）が明記されているか
- [ ] イラストレーター自身の利用範囲（ポートフォリオ等）が合意されているか
- [ ] 納品形式（PSD レイヤー分け + PNG）が指定されているか
- [ ] 第三者の権利非侵害の保証条項があるか
- [ ] 修正回数と追加費用の条件が明記されているか
- [ ] 支払条件（着手金・検収後支払い）が明記されているか
- [ ] 秘密保持条項があるか（リリース前のイラスト公開禁止等）
- [ ] 納期が明記されているか
- [ ] クレジット表記の方針が合意されているか

## 4. 発注時の注意事項

### AI生成物の利用制限

契約書に以下を明記することを推奨:

```
成果物は乙自身の創作によるものとし、AI画像生成ツール
（Stable Diffusion、Midjourney、DALL-E等）の出力を
そのまま使用または大幅に依拠して制作してはならない。
```

**理由:** AI生成物は著作権の帰属が不明確であり、学習データに含まれる他者の著作物との類似性リスクもあります。

### トレース・模倣の禁止

既存のイラスト・写真のトレースや明確な模倣を禁止する条項を設けてください。SNSでの炎上リスクにもつながります。
