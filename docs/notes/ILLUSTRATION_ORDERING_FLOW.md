# イラスト発注の進め方

イラストレーターとの契約から納品までの実務フローをまとめる。

---

## 1. 契約構造

```
基本契約（電子契約サービスで1回だけ締結）
│   利用許諾、改変同意、秘密保持、権利保証、AI禁止 etc.
│
├── 個別発注書 第1号（メールで送付 → メール返信で承諾）
├── 個別発注書 第2号
├── 個別発注書 第3号
└── ...
```

- **基本契約:** イラストレーター1人につき1回。電子契約サービス（クラウドサイン等）で締結
- **個別発注書:** 追加発注のたびにメールで送付。電子契約サービスは不要

---

## 2. 連絡手段の使い分け

| 用途 | 手段 | 理由 |
|------|------|------|
| **基本契約の締結** | 電子契約サービス | 法的証拠力の確保 |
| **個別発注書の送付・承諾** | メール | タイムスタンプ・検索性・保全性に優れる |
| **日常のやり取り（ラフ確認、修正相談等）** | DM（Twitter/Discord 等） | イラストレーターが慣れた手段で円滑に |
| **設定資料・参考画像の共有** | メールまたはクラウドストレージ | 添付ファイルの容量制限を考慮 |
| **納品** | クラウドストレージ（Google Drive 等） | 大容量PSDファイルの受け渡し |

イラストレーターへの伝え方: 「普段の連絡はDMで大丈夫です。発注のときだけメールで送りますね」

---

## 3. 電子契約サービスの選定

基本契約の締結に使用する。個別発注書には不要。

| サービス | 無料枠 | 備考 |
|---------|--------|------|
| GMOサイン | 月5件 | 2ヶ月で10人分カバー可能 |
| クラウドサイン | 月3件 | 4ヶ月で10人分カバー可能。国内シェア最大 |
| freeeサイン | 月1件 | 少数なら可 |

受信側（イラストレーター）はアカウント不要。メールのリンクから内容確認 → 同意ボタンで完了。

---

## 4. 発注フロー（イラストレーター1人あたり）

### Phase 0: イラストレーター選定

1. ポートフォリオを確認し、画風・得意分野が陣営のテーマに合うか判断
2. DM等で依頼の打診（概要を説明、企画書を共有）
3. 報酬・スケジュールの大枠を合意

### Phase 1: 基本契約の締結

1. 契約書テンプレート（[ILLUSTRATION_CONTRACT_TEMPLATE.md](ILLUSTRATION_CONTRACT_TEMPLATE.md)）の [TODO] を埋める
2. PDF化して電子契約サービスにアップロード
3. イラストレーターにメールで送信
4. 双方が電子署名して締結完了

### Phase 2: 個別発注

1. 個別発注書テンプレート（基本契約書の末尾）に記入
2. キャラクター設定書を添付してメールで送付
3. イラストレーターがメール返信で承諾（5営業日以内に拒否がなければ自動承諾）
4. 着手金（50%）を振込

### Phase 3: 制作・確認

```
ラフ提出 → 甲が確認（7営業日以内）→ 承認 or 修正依頼
    ↓
線画提出 → 甲が確認 → 承認 or 修正依頼（2回まで）
    ↓
着色・仕上げ → 甲が確認 → 承認 or 修正依頼（2回まで）
    ↓
納品（PSD + PNG をクラウドストレージにアップロード）
```

日常のやり取り（ラフの方向性相談、参考画像の共有等）はDMでOK。

### Phase 4: 検収・支払い

1. 納品物を確認（10営業日以内）
2. 問題なければ検収完了を通知
3. 残額（50%）を振込

## 5. 発注計画

[PROJECT_PROPOSAL.md](../PROJECT_PROPOSAL.md) のスケジュールに基づく。

| フェーズ | 時期 | 内容 | 枚数 |
|---------|------|------|------|
| Phase 1 | 2026年 5〜7月 | 各陣営の主要キャラクター | 約10枚 |
| Phase 2 | 2026年〜2027年 | 残りのキャラクターイラスト | 約30枚 |
| Phase 3 | 順次 | アイコン・エフェクト等の概念カード | 約80枚 |

- Phase 1 で方向性を確認してから Phase 2 に進む
- リリース時点では仮イラストを使用し、完成次第順次差し替え
- イラストレーターのペースを尊重し、納期は余裕を持って設定

---

## 6. 記録の管理

| 対象 | 保管場所 | 保管期間 |
|------|---------|---------|
| 基本契約書（署名済みPDF） | 電子契約サービス + ローカルバックアップ | 永久 |
| 個別発注書（メール） | メールボックス + PDF保存 | 永久 |
| 納品物（PSD, PNG） | クラウドストレージ + ローカルバックアップ | 永久 |
| やり取りの記録（DM） | スクリーンショット保存（重要なやり取りのみ） | 任意 |
| 支払い記録（振込明細） | 経理記録として保管 | 7年（税法上の保管義務） |
