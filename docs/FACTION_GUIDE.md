# Overload Party — 陣営ガイド

**はじめてのプレイヤーのための陣営選びの手引き**

---

## どの陣営を選ぶ？

Overload Party には **4つの陣営**がある。どれを選んでも勝てるけど、得意な戦い方がまるで違う。
自分のプレイスタイルに合った陣営を見つけよう。

```
      しゅがーらぼ（速攻）
       ↗        ↘
  調律部（経済）←― 天気使い（防御）

     SHE（万能）= どこにでも対応
```

> しゅがーらぼ は調律部に強く、調律部は天気使いに強く、天気使いはしゅがーらぼに強い。
> SHE はどの相手ともそこそこ戦える万能タイプ。

---

## SHE（Smile Horizon Express）

**「みんなで強くなる、何でもできる万能チーム」**

SHE のカードは1枚1枚は平凡。でも場に SHE のカードが並ぶほど、チーム全体がどんどん強くなる。
攻撃・防御・回復のどれもそこそこできて、状況に合わせて柔軟に動けるバランス型。

| | |
|---|---|
| **勝ちパターン** | カードを並べてシナジーを発動。Marketplace で稼ぎ、CDN で全体強化して押し切る |
| **得意な展開** | 場のカードが揃う中盤以降。仲間が増えるほど強い |
| **苦手な展開** | 序盤のパワー不足。1枚で試合を決めるエースがいない |
| **おすすめの人** | はじめてのプレイに最適。柔軟に戦いたい人 |

### Starting Field のおすすめ

**フロントエンド: SHE Compute - えくぼ** + **バックエンド: SHE RDB - アデリース** — 迷ったらこれ。バランスが良い基本の組み合わせ。

---

## 天気使い

**「倒れない。何度でも立ち上がる鉄壁の守り」**

全陣営で最も硬い。カードの耐久値が高く、倒されても復活カードで何度でも立ち上がる。
相手が攻撃で Budget を使い果たすのをじっと耐えて待つ、長期戦の王者。

| | |
|---|---|
| **勝ちパターン** | 復活カードで場を維持し続け、相手が息切れしたところで逆転 |
| **得意な展開** | 長期戦。ターン数が増えるほど有利になる |
| **苦手な展開** | 自分から押し切る展開。Revenue 差で押されると苦しい |
| **おすすめの人** | 守って守って最後に勝つのが好きな人。じっくり派 |

### Starting Field のおすすめ

**フロントエンド: 天気使い VM - ソラ** + **バックエンド: 天気使い RDB - シグレ** — ゲーム最高クラスの耐久で序盤を安定させる。

---

## しゅがーらぼ

**「最強火力で先に倒す。壊れる前に壊せ！」**

攻撃力は全陣営トップ。AI/ML カードが最も充実していて、一撃の破壊力は圧倒的。
その代わりカードは脆い。先に殴り勝つか、先に崩壊するかの真っ向勝負。

| | |
|---|---|
| **勝ちパターン** | 序盤から猛攻。高火力で相手のカードを全滅させてシステムダウン勝利 |
| **得意な展開** | 序盤〜中盤の速攻。手を止めなければ最強 |
| **苦手な展開** | 長期戦。攻めが止まると Budget が回復しない |
| **おすすめの人** | ガンガン攻めたい人。リスクを取って爆発力を楽しみたい人 |

### Starting Field のおすすめ

**フロントエンド: しゅがーらぼ Compute - コンフェッティート** + **バックエンド: しゅがーらぼ RDB - エクレアーエル** — 全 Compute 最高の攻撃力で初手から圧力をかける。

---

## 調律部

**「最強のデータベースで、金の力で圧倒する」**

DB（データベース）の性能が他陣営の約1.5倍。毎ターンの収入（Revenue）が圧倒的に多い。
CDN も AI も持たない不器用な陣営だが、DB を守り抜けば Budget の差で押し潰す。

| | |
|---|---|
| **勝ちパターン** | DB を育てて Revenue で圧倒。Budget 差で相手を破産に追い込む |
| **得意な展開** | DB が育った中盤以降。Revenue の差が開くほど有利 |
| **苦手な展開** | DB を狙い撃ちされる展開。CDN や AI がなくカード種類が少ない |
| **おすすめの人** | 経済で勝つのが好きな人。「守るべきもの」を守り抜く戦いが好きな人 |

### Starting Field のおすすめ

**フロントエンド: 調律部 Compute - コンタータ** + **バックエンド: 調律部 DB - 音の魔術師〈マジシャン・オブ・ミュージック〉** — 高い Yield を生かして初手から他陣営を圧倒する。
