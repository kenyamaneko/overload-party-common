# overload-party テスト固有ルール (overlay)

共通ルール (`keyandnotes-rules` の `rules/testing.md`) を土台に、overload-party 固有の具体化を定義する。CLAUDE.md の「ファイル編集前のルール適用手順」に従い、テスト作成時に共通とあわせて Read する。

## [overload-party] テストデータ
